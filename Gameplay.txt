========================================================
  REGLES DU JEU
========================================================

OBJECTIF
--------
Éliminer 5 des personnages actifs et sur le banc adverse.

MISE EN PLACE
-------------
- Chaque joueur commence avec 5 cartes en main
- On pose 1 carte Personnage en position ACTIVE (obligatoire)
- On peut poser jusqu'à 3 cartes Personnage sur le BANC
- Les Sorts et Objets se jouent depuis la main pendant son tour

ENERGIE
-------
- Commence à 100% pour TOUS les personnages
- Se dépense quand on attaque
- Se recharge de +20% à chaque tour pour le personnage ACTIF
- Se recharge de +30% à chaque tour pour les personnages sur le BANC
  (le banc recharge plus vite, comme dans le vrai Pokémon TCG !)
- Maximum 100%, minimum 0%
- Si énergie insuffisante → impossible d'attaquer ce tour

TOUR DE JEU
-----------
1. Piocher 1 carte
2. Jouer des Objets ou Sorts depuis la main (optionnel)
3. Attaquer avec le personnage ACTIF (optionnel)
4. Si le personnage actif est KO → on remplace depuis le banc

REMPLACEMENT
------------
- Si personnage actif KO → le joueur DOIT mettre un perso du banc en actif
- Si banc vide et actif KO → DEFAITE IMMEDIATE

SYNERGIES
---------
Chevalier + Samourai  → "Code de l'Honneur" : +15 ATQ aux deux
Cowboy + Soldat       → "Feu Croisé"        : +30 ATQ combinées
Samourai + Cowboy     → "Duel Légendaire"   : premier attaquant fait x2 dégâts
Chevalier + Soldat    → "Bouclier & Blindage": le plus défensif protège l'autre

========================================================
  LOGIQUE A CODER 
========================================================

Joueur.java
-----------
- Personnage actif         : Personnage personnageActif
- Banc (max 3)             : List<Personnage> banc
- Main (max 7)             : List<Carte> main
- Pioche                   : Deck deck

Personnage.java
---------------
- int pv
- int pvMax
- int atq
- int energie = 100        // commence à 100%
- boolean estActif         // true = position active, false = banc
- Objet objetEquipe        // null si rien équipé

void rechargerEnergie() {
    if (estActif) energie = Math.min(100, energie + 20);
    else          energie = Math.min(100, energie + 30);
}

boolean peutAttaquer(int coutEnergie) {
    return energie >= coutEnergie;
}

Partie.java
-----------
- Vérifier si banc vide + actif KO → defaite
- Appliquer recharge énergie à TOUS les persos chaque début de tour
- Gérer les synergies inter-factions

Combat.java
-----------
- Calculer dégâts : atq attaquant - 0 (pas de DEF !)
- Appliquer synergies
- Gérer effets spéciaux (headshot, embuscade, etc.)
- Random pour effets probabilistes

========================================================
  EFFETS SPECIAUX A CODER (Raphael)
========================================================

Headshot (30%)
  → Random rand = new Random()
  → if(rand.nextInt(100) < 30) adverse.setEtourdi(true)

Coup de Chance (50/50)
  → if(rand.nextBoolean()) soigner() else attaquer()

Embuscade
  → boolean piegeActif dans Joueur.java
  → si piegeActif == true → retourner dégâts sur attaquant

Drone de Combat
  → List<Effet> effetsActifs dans Partie.java
  → appliqué à chaque debutDeTour()

Synergies
  → stream().filter(c -> c.getFaction() == Faction.X).count() >= 2

Grenade EMP
  → for(Objet o : adverse.getObjetsEquipes()) o.setActif(false)

Sniper Elite (cible banc)
  → Combat.java : autoriser ciblage de banc[index] si Sniper actif

Recharge énergie banc/actif
  → for(Personnage p : joueur.getBanc()) p.rechargerEnergie()
  → joueur.getActif().rechargerEnergie()

========================================================
  RAPPELS IMPORTANTS
========================================================
- JavaFX uniquement, pas Swing
- Énergie commence à 100% (pas 33% comme Rocket League)
- Banc recharge +30% par tour, Actif +20% par tour
- Pas de DEF, seulement ATQ
- 5 cartes en main au départ comme Pokémon TCG Pocket
- 1 actif + max 3 sur le banc
- Sorts gratuits en énergie (coût 0%)
- Objets équipés permanents sur un personnage
- Commits réguliers sur GitHub chaque mercredi !
